# بصيرة

أداة عربية للتحقق من الادعاءات حول الإسلام، ضمن المسار ٠٤ من تحدي الذكاء الاصطناعي في خدمة المحتوى الإسلامي.

[التجربة المباشرة](https://basira.basira-api.workers.dev/) · [المستودع](https://github.com/Moh721-VPS/basira) · [تصميم الواجهة](https://www.figma.com/design/JPT2ECVyHsTo7q4MfiwM35)

تدعم بصيرة العربية فقط، في الواجهة والتحقق والتفريغ الصوتي والمحادثة المباشرة. تُرفض الادعاءات الإنجليزية والمختلطة قبل استدعاء النموذج. لا تعرض نتائج القرآن ترجمة إنجليزية؛ تعرض النص العربي الأصلي.

تقسم الأداة النص إلى ادعاءات مستقلة، وتسترجع الأدلة من المصادر المعتمدة، ثم تفحص ما إذا كان الدليل يسند جميع أجزاء كل ادعاء. يعيد النموذج معرّفات الأدلة فقط، ويربطها الخادم بروابط المصادر الحقيقية. لا تقدم بصيرة فتاوى أو أحكاماً شخصية، ولا تجيب عن المعرفة الدينية من ذاكرة النموذج.

الميزات: أمثلة عربية، فلاتر الحالات، عرض النص الأصلي وروابطه، نسخ وتنزيل التقرير، إدخال صوتي مع مراجعة التفريغ قبل التحقق، قراءة التقرير، ومحادثة صوتية عربية مباشرة. يرحب المساعد بالمستخدم، ويقرأ الإجابة دون أسماء الناشرين أو الروابط؛ تبقى المراجع ظاهرة على الشاشة. الإجابات المعرفية مقيدة بالنصوص المسترجعة.

## التشغيل

يتطلب المشروع Node.js بإصدار 22.12 أو أحدث وpnpm بإصدار 11.25.0.

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm dev:api
pnpm dev:web
```

شغّل آخر أمرين في نافذتين منفصلتين، ثم افتح http://127.0.0.1:5173. الوضع المحلي تجريبي حتى تضبط الإعدادات.

ضع المتغيرات في الملف المحلي المستبعد من Git: `api/.dev.vars`. أسماء المتغيرات في [.env.example](.env.example). لا تضع مفاتيح الخدمة في الواجهة أو المستودع.

```dotenv
GEMINI_API_KEY=
GEMINI_MODEL=gemini-3.1-flash-lite
MOCK_MODE=false
```

إعداد الصوت في [VOICE.md](VOICE.md)، والمحادثة في [LIVE-DISCUSSION.md](LIVE-DISCUSSION.md)، والنشر في [DEPLOY.md](DEPLOY.md). يتطلب النشر ضبط الأسرار في Cloudflare، ثم `pnpm check:deploy` و`pnpm deploy`.

## واجهة التحقق

`POST /api/verify` مع `Content-Type: application/json`:

```json
{ "text": "الصلاة من أركان الإسلام الخمسة.", "lang": "ar" }
```

الحد الأقصى ١٠٠٠٠ حرف وخمسة ادعاءات. القيمة اللغوية الوحيدة المقبولة `ar`. النتائج: `SUPPORTED` (مدعوم)، `NEEDS_MORE_VERIFICATION` (يحتاج إلى مزيد من التحقق)، `REFER_TO_SPECIALIST` (يُحال إلى مختص). فشل الخدمة ينتج `SYSTEM_ERROR`، ولا يُعرض باعتباره نقصاً في الأدلة. جاهزية الإعدادات في `GET /api/health` لا تثبت أن المفتاح أو حصة الخدمة صالحان.

## حدود التقييم

اختبارات التطوير وفحوص الخدمة ليست قياساً لدقة شرعية أو مجموعة مراجعة بشرية مستقلة. مجموعة الأربعين ادعاءً التي سيعدها الزميل ما زالت معلقة. قد تسبب حصص الخدمة أو تعطل المصدر خطأ خدمة. تحليل روابط الشبكات الاجتماعية والتحقق دون اتصال والتطبيقات الأصلية غير منفذة.
